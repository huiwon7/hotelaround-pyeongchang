# 호텔어라운드 평창 · 랜딩페이지

해발 700m 평창 봉평 고원에 자리한 사계절 라이프스타일 리조트 **호텔어라운드 평창**의 소개 페이지입니다.
객실이 아니라 '평창에서의 하루'를 제안한다는 콘셉트로 만들었습니다.

🔗 **미리보기** — https://huiwon7.github.io/hotelaround-pyeongchang/

---

## 구성

| 섹션 | 내용 |
|---|---|
| 평창에서의 하루 | 도착부터 잠들기까지의 시간대별 제안 |
| 사계절 | 봄·여름·가을·겨울 패널과 계절별 추천 스팟 |
| 평창 인스타 핫플 | 포토스팟 매스너리 + 감성 카페 |
| 평창의 맛 | 봉평 메밀·태기산 산채 등 주변 맛집 |
| 객실 | 7개 타입 × 5컷 갤러리 (라이트박스) |
| 시설 | 라운지·바비큐·웰니스·키즈·피트니스 |
| 시그니처 패키지 | 별빛숲 1박 2일 프로그램 |
| 오시는 길 | 자가용·KTX·시외버스 + 주변 소요시간 |
| FAQ | 자주 묻는 질문 11문항 |
| 예약 문의 | 문의 폼 |

## 기술 메모

- **의존성 없는 단일 HTML** — 빌드 도구, 프레임워크, 번들러를 쓰지 않습니다. CSS와 JS 모두 인라인.
- **반응형** — CSS Grid / `clamp()` 기반. 모바일에서는 하단 고정 CTA로 전환됩니다.
- **접근성** — 객실 갤러리는 키보드(←/→/ESC)와 스와이프를 지원하고, FAQ는 `<details>`라 JS 없이도 동작합니다.
- **이미지 최적화** — 최장변 1600px·JPEG 품질 82로 재인코딩해 36.8MB → 12.3MB로 줄였습니다. 전 이미지 `loading="lazy"` + `width`/`height` 지정으로 레이아웃 이동(CLS)을 없앴습니다.
- **SEO** — `Hotel`·`FAQPage` 구조화 데이터, Open Graph, `sitemap.xml` 포함.
